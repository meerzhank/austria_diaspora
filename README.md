# Kyrgyz Diaspora in Austria

Official community website for the Kyrgyz Diaspora in Austria — supporting Kyrgyz nationals and people of Kyrgyz descent living across the country, and promoting Kyrgyz culture and traditions.

🔗 **Live site:** https://meerzhan.kanatbekova.github.io/kyrgyz-diaspora-austria/

## About

This is a single-page site built with plain HTML, CSS, and vanilla JavaScript — no build tools or frameworks required. It covers:

- **About** — who we are and our story
- **Mission** — our core goals as a community organisation
- **Cultural Activities** — events like Nooruz, craft workshops, and culinary gatherings
- **Membership** — how to get involved
- **Contact** — location, phone, email, social links, and a contact form

## Editing content

All content lives in `index.html`. Key things to update with real details:

| What | Where |
|---|---|
| Address, phone, email | `<div class="contact-info">` section |
| Social media links | `<div class="socials">` section |
| About/Mission copy | `<section class="about">` and `<section class="mission">` |
| Event details | `<section class="activities">` |
| Contact form | 

## Local preview

Just open `index.html` directly in a browser — no server needed.

## Deployment

This site is hosted with **GitHub Pages**.

1. Push changes to the `main` branch
2. GitHub Pages automatically rebuilds and redeploys within a minute or two
3. Settings: repo → **Settings → Pages** → source set to `main` / `root`
